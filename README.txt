CONO PIZZA — файли сайту
1. Розпакуйте ZIP.
2. Відкрийте папку cono-pizza-site.
3. Двічі клацніть index.html або відкрийте його через Chrome/Safari.
4. Для публікації в інтернеті завантажте вміст цієї папки на хостинг статичних сайтів (наприклад Cloudflare Pages).

Меню, ціни, вагу та контакти можна буде редагувати у файлі script.js / index.html.
Для кожної позиції меню призначено окреме тематичне ілюстративне фото з Unsplash; це не власні фото закладу.
